# Elena Example

This package provides CRX description files and utilities for robot simulation, including PyBullet integration.

## Installation

You can install this package directly from GitHub:

```bash
pip install git+https://github.com/swilcock0/elena_example.git
```

## Usage

This package is designed to be used in Grasshopper Python scripts or standalone Python scripts. It includes:

- CRX description files
- Utilities for robot simulation

## Requirements

- Python 3.6+
- `numpy`
- `matplotlib`
- `pybullet`
